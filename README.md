# RedFlag — The Fraud Files

## 📌 About the Project

**RedFlag — The Fraud Files** is a SQL-based fraud detection project developed using MySQL.

The project analyzes transaction data and identifies suspicious patterns using SQL queries.

## 🔍 Fraud Patterns

The project detects 12 fraud patterns:

1. Velocity Fraud
2. Round-Amount Clustering
3. Card Testing
4. Failed-Then-Succeeded
5. Odd-Hour Concentration
6. Mule Accounts
7. Refund Abuse
8. Merchant Collusion
9. Just-Under-Threshold
10. Dormant-Then-Active
11. Velocity Spike
12. Geographic Impossibility

## 🛠️ Technologies Used

* MySQL
* SQL
* CTEs
* Window Functions
* JOINs
* Aggregate Functions
